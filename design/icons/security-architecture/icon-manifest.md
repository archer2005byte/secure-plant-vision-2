# Security Architecture Icon Manifest

## Family and licensing decision

- **Delivered family:** Security Architecture Original Outline v1.
- **Status:** Original project artwork; no third-party icon geometry was copied, traced, scraped or embedded.
- **Geometry:** 32×32 viewBox, 2px rounded strokes, outline construction, no gradients, shadows, 3D styling or vendor marks.
- **Colour model:** SVGs use `currentColor`; restrained detail uses `--icon-accent`. Recommended light surface: `color: #1A1A24`. Recommended dark surface: `color: #FFFFFF; --icon-accent: #FFE600`.
- **Streamline Ultimate Regular:** no licensed SVG package was supplied locally, so Streamline assets are not used. A valid Streamline Ultimate licence and supplied source files would be required before substituting them.
- **Font Awesome Pro:** not used, avoiding mixed-family output and an unverified Pro licence dependency.
